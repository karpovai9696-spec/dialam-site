О услугах центра

Центр «Диалам+» в Волжске оказывает специализированную медицинскую помощь пациентам с хронической болезнью почек. Основное направление — амбулаторный гемодиализ по полису ОМС.

Бесплатно по полису ОМС

Амбулаторный гемодиализ

Программный гемодиализ для пациентов с хронической почечной недостаточностью. Работаем по полису ОМС, 3 смены — понедельник–суббота с 07:00 до 22:00.

Записаться на консультацию

Гостевой диализ

Принимаем пациентов из других регионов по полису ОМС. Свободные места есть.

Консультации специалистов

Врач-нефролог, врач-диализист и старшая медицинская сестра — консультации бесплатно по полису ОМС.

Регулярный контроль показателей и наблюдение специалистов в рамках программы лечения.
