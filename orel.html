О центре

Филиал «Орёл» — центр амбулаторного гемодиализа для пациентов с хронической болезнью почек. Здесь проводят программный гемодиализ, принимают гостевых пациентов и консультируют по вопросам заместительной почечной терапии.

Центр работает по полису ОМС. Приём ведётся по предварительной записи; график работы — понедельник–суббота с 06:00 до 23:00, воскресенье — выходной.

Услуги

Программный гемодиализ

Плановые процедуры для пациентов с хронической болезнью почек под контролем медицинской команды.

Гостевой диализ

Проведение сеанса для пациентов, временно находящихся в Орле и Орловской области.

Консультация нефролога

Приём врача-нефролога по полису ОМС: оценка функции почек и подбор терапии.

Вакансии филиала

Врач-нефролог

Полная занятость · оплата по договорённости

  • Обязанности: амбулаторный приём пациентов с хронической болезнью почек, подбор и контроль программы диализа.
  • Требования: высшее медицинское образование, аккредитация по нефрологии/терапии.

Инженер по медицинскому оборудованию

Полная занятость · оплата по договорённости

  • Обязанности: обслуживание аппаратов гемодиализа, подготовка техники к сеансам, ведение документации.
  • Требования: профильное техническое образование; опыт приветствуется.
