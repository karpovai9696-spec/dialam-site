# Диалам+ — центр амбулаторного гемодиализа в Волжске

Статический прототип нового сайта сети центров амбулаторного гемодиализа «Диалам+»
(площадка в г. Волжск, Республика Марий Эл). Свёрстан по дизайн-макетам, запускается локально
без сервера, сборки и внешних зависимостей.

**Живая демонстрация:** https://karpovai9696-spec.github.io/dialam-site/

## Быстрый старт

Откройте `index.html` двойным кликом — сайт работает по протоколу `file://`.
Шрифты (Onest), изображения и PDF-документы лежат локально в `assets/`.

## Правила разработки (важно для ИИ-агента)

1. **Не изменяйте существующие файлы**, если задача прямо этого не требует.
2. Шапку (`<header class="site-header">…</header>`) и подвал (`<footer class="site-footer">…</footer>`)
   копируйте из актуальной страницы (например, `strahovye-kompanii.html`) без изменений, кроме
   активного пункта навигации.
3. Используйте готовые классы и CSS-токены из `css/base.css` и `css/inner.css`
   (`.container`, `.glass-card`, `.content-card`, `.content-card__title`, `.btn*`,
   `.breadcrumbs*`, `.sidebar*`, `.page-title`, `.content-stack`). Не переопределяйте их.
4. Новые стили — только в отдельном файле `css/<страница>.css`. Не вставляйте `<style>` в HTML.
5. Внутренние страницы строятся по шаблону: `.container > .inner-layout > .sidebar + .content-col`,
   внутри `content-col` — `.breadcrumbs`, `h1.page-title`, `.content-stack` с карточками.
6. Обязательный юридический блок в подвале (реквизиты, лицензия, политика ПДн, карта сайта,
   поиск, предупреждение о противопоказаниях) не удалять и не сокращать.
7. Режим слабовидящих: любые новые компоненты должны иметь состояние `html.a11y-mode`
   (белый фон, чёрная рамка 2px, без теней).
8. Внешних ресурсов (CDN, внешние шрифты, карты-iframe, аналитика) быть не должно.
9. Иконки — inline SVG (stroke: currentColor). Изображения — только из `assets/img/`.
10. Адаптивность обязательна: контрольные ширины 1440 / 1280 / 1024 / 768 / 390 px,
    горизонтального скролла быть не должно.
